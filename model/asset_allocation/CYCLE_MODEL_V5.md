# v5.1 周期模型可复现口径

本文只记录模型公式和治理口径，不替代数据连接器的字段映射。Wind、iFind、米筐的指标代码必须先由连接器做五行样本、发布日期/可得日、修订口径和历史覆盖验证；未完成绑定的字段不得因为名称近似而标记为 D3。

## 共同时间点与标准化

- 观测先由编排器移动到 `available_time`，要求 `available_time >= observation_period`，并保留 `vintage/revision`；周期模型只消费 `_pit_verified=True` 的行。
- 水平序列同比为 `YoY_t = 100 * (x_t / x_{t-12} - 1)`；已由数据源给出的同比序列不重复变换。
- 标准分只使用当前月之前最多 60 个月：`z_t = clip((x_t - median(H_{t-1})) / (1.4826 * MAD(H_{t-1})), -4, 4)`。MAD 退化时使用样本标准差。显式传入 `train_end` 后，标准化样本和转移参数在训练期末冻结。
- 三个月动量先算 `Delta3_t = x_t - x_{t-3}`，再用同样的一步滞后方法标准化。
- 因子缺失不做近似值填补；可用因子可形成展示概率，但只要缺一项必需因子或 PIT 未验证，`eligible_for_views=False`。

## 基钦周期

- 必需库存轴：工业企业产成品存货同比；PPI 不能作为库存替代。
- 必需需求轴：工业企业营业收入同比；PMI 新订单只作领先确认。
- `Demand = mean(z_营业收入, z_PMI新订单, z_Delta3需求)`，`Inventory = mean(z_产成品存货, z_Delta3存货)`，均只平均当时可用的成分。
- 四个发射中心依次为被动去库 `(+, -)`、主动补库 `(+, +)`、被动补库 `(-, +)`、主动去库 `(-, -)`。
- 每阶段持续期先验为最短 3 个月、期望 9 个月、最长 18 个月；输出完整四状态后验而非单一符号标签。

## 朱格拉周期

- 四个必需支柱为制造业固定资产投资、企业中长期贷款、工业产能利用率、工业企业利润；任何支柱缺失均阻断 D3。
- `Level` 为四支柱因果标准分的等权均值，`Momentum` 为四支柱三个月动量标准分的等权均值。
- 四个发射中心依次为修复期 `(Momentum+, Level-)`、繁荣早期 `(+,+)`、繁荣晚期 `(-,+)`、出清期 `(-,-)`。
- 四阶段持续期（最短/期望/最长月数）为 `12/21/36`、`18/33/48`、`18/30/48`、`12/24/42`，一轮期望合计 108 个月，对应 7—11 年中枢。

## 中国版美林时钟

- 必需六轴：增长、通胀、信用、流动性、估值、风险偏好。
- 增长至少含制造业 PMI；通胀同时要求 CPI 与 PPI；信用要求社融存量同比；流动性要求 M2；估值优先股权风险溢价、否则反向估值分位；风险偏好为股债相对动量。
- 发射似然同时使用六轴；增长/通胀决定钟面象限，信用、流动性、估值与风险偏好用于中国环境的确认和否决。每个阶段持续期先验为 `3/6/15` 个月。
- 页面继续输出 `growth_score/inflation_score/credit_score/liquidity_score` 兼容字段，同时新增六轴证据，不再把增长与通胀两个指标冒充完整中国版美林时钟。

## 普林格六阶段

- 输入严格为国债、权益、非黄金商品三类总回报；黄金列从读取、波动、动量、似然和转移学习中全部排除。
- 对每类市场计算 3/6/12 月复合收益除以同期限尾随波动，权重为 0.20/0.35/0.45；牛市概率为 `sigmoid(1.35 * score)`。
- 六阶段发射似然是三市场牛熊伯努利似然的乘积；阶段持续期先验为 `2/4/10` 个月。
- 转移只允许退出后的阶段转移，持续性由显式持续期分布处理；软转移计数仅在 `month <= train_end` 更新，之后冻结。

## 显式持续期状态模型

每个经济状态展开为 `(state, elapsed_month)`。持续期分布是在 `[minimum, maximum]` 整数支持上、满足指定期望值的最大熵指数倾斜分布；离开危险率为 `h(d)=P(D=d)/P(D>=d)`。前向递推分别计算留在下一持续期单元的质量和退出至下阶段首月的质量，再乘当期发射似然并归一化。该递推只使用当期及此前信息；测试期既不更新持续期先验，也不更新退出转移矩阵。

## 康波与 BL 观点

康波缺少多个可独立检验的 40—60 年完整样本，固定为研究展示，置信度为 0、`eligible_for_views=False`，风险预算和 BL 周期贡献严格为零。其余通过准入的概率特征进入训练窗内扩展回归，形成固定三条相对观点：权益减国债、非黄金商品减国债、黄金减国债；`Omega` 使用扩展样本预测误差的完整半正定协方差矩阵。
