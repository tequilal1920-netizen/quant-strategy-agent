# 外层整理说明

`G:\中信建投` 的中文结构用于日常浏览和交接；`agent/` 是实际 Git 仓库和正式运行源码。外层目录中的大部分模型入口是目录连接，目的是让“数据看板、资产配置、行业风格、因子实验室、技术分析、组合优化、数据库、公网、environment、mcp、skill”按用户视角排布，同时保持唯一正式源码不分叉。

不能上传 GitHub 的内容：

- `reference/SOP` 中的 Word/Excel 文档；
- 本地数据库、缓存、授权数据；
- 私密环境变量、账号、token、cookie；
- 历史归档中的旧发布包和中间输出。

可上传 GitHub 的内容：

- `agent/` 内正式源码；
- `agent/ai-models` 和 `agent/skill` 的公开模型 Skill；
- `agent/mcp` 的公开 MCP 骨架；
- `agent/environment/workspace_layout` 的结构说明。
