# 图表绘制 Skill

## 触发

当任务涉及网页图表、回测图、年度收益表、色阶表格、双轴曲线、净值回撤、行业风格图、资金面图、内需股图或用户明确要求“参考图表绘制 skill”时使用。

## 参考

正式参考目录为 `G:\招银理财\skill\图表绘制`。执行前优先读取该目录的画布、字体、线宽、色阶、图例和表格规范。

## 纪律

1. 中文优先使用楷体族，英文和数字使用 Arial。
2. 线条粗细按当前项目统一倍数执行，所有板块保持一致。
3. 表格应使用真实 HTML 或 Excel 表格，不用截图替代。
4. 色阶只改变条件格式条，不额外加粗文字，不整格污染背景。
5. 生成后必须用浏览器或图像尺寸检查确认不重叠、不截断、不空白。
