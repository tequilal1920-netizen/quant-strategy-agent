# 技术分析三轨模型源码说明

本目录对应网页一级栏目“技术分析”。当前版本不是单一 K 线规则，而是三条并行链路：

- 模型一：纯技术信号栈，负责用本地技术因子完成个股择时与全市场轮动。
- 模型二：LLM 记忆多周期，负责学习历史 K 线形态、同类股票模式和策略记忆，并给出可解释判断。
- 模型三：全历史低频技术拟合，按最新需求不做训练/测试划分，直接用全部成熟历史样本学习和选择低频候选，并输出当前位置。

模型一和模型二仍保留严格治理：训练集提出候选，验证集选择候选，封存测试只报告。模型三是全样本回溯拟合研究版，不声明样本外验证。

## 模型一：纯技术信号栈

核心源码：`framework/backtest/technical_signal_model.py`。

流程如下：

1. 数据入库：读取本地时点化 OHLCV、成交额、股票状态和行业映射。
2. 因子补全：从基础量价序列生成趋势、突破、回撤、量价、波动和防守六类信号。
3. 信号标准化：每个交易日做横截面排序，行业内再标准化，避免单一行业或市值暴露主导。
4. 权重学习：只用训练期未来收益计算各信号族 IC，低质量信号降权，不能使用验证或测试标签。
5. 个股择时：用训练期分位数确定买入、减仓、清仓阈值，输出单股历史判断和当前判断。
6. 横截面轮动：把股票按综合分、残差增量和风险预算形成候选组合，扣除换手成本后回测。

## 模型二：LLM 记忆多周期

核心源码：`model/kline_memory_learning/single_stock_analyzer.py` 与 `model/kline_memory_learning/cohort_wyckoff_learning.py`。

流程如下：

1. Wyckoff 形态识别：从单股复权 OHLCV 逐 K 线识别 Spring、Upthrust、SOS、SOW、LPS、LPSY、买入/卖出高潮、吸筹和派发等价量结构。
2. Predictor：当前形态只检索最多五条最相关情境记忆，不读取六类技术因子横截面分数。
3. Critic：形态成熟后用后续持有窗收益验证原判断是否兑现，记录成功、失败、最大顺逆向波动和失效条件。
4. Reflector：新增记忆按 `add/skip/replace/branch` 处理；同情境更优则替换，语义重复则跳过，失败条件不同则分支，单档案最多 120 条、单分支最多 3 次精炼。
5. Evolver：在严格跨股共识、个股与同类平衡、行业情境分支之间做候选进化，再交给本地规则引擎、回测门和治理门决定是否接受。
6. 输出：个股历史买卖点、策略与原股价净值、记忆进化过程、当前技术信号、当前五档仓位和中文学习记录。

即时批量绘图入口：`model/kline_memory_learning/run_wyckoff_memory_batch.py`。该脚本用于用户指定少量个股的快速可复现输出，复用同一 Wyckoff 事件库和情境记忆合并规则，生成每股“买卖点净值图”和“记忆进化图”。当前优化版包含 `FullHistoryContextMemoryEvolver` 与 `five_state_path_memory_evolver`：前者在全历史成熟情境上选择持有窗和冷却期候选，后者把成熟后的趋势/回撤情境压缩为 0%、25%、50%、75%、100% 五档仓位路径，并用换手惩罚控制买卖点频率，以提升历史收益、Sharpe、回撤和年度超额胜率；该模式是全历史研究回放，不等同严格样本外生产验证。

补充研究入口：`model/kline_memory_learning/run_single_stock_turning_point_research.py` 与 `run_single_stock_turning_point_batch.py` 只属于全历史拐点教师研究，用于收益捕捉草案和图形参考，不等同于上述 LLM/Wyckoff 记忆学习框架，回答时不得把它与模型二正式逻辑混为一谈。
## 模型三：全历史低频技术拟合

新增源码入口同样在 `run_multiscale_expert_challenger.py`，核心信号来自 `technical_signal_model.py`。

流程如下：

1. 使用全部已成熟历史收益估计六类技术信号族权重，不再划分训练/验证/测试。
2. 生成纯技术综合、突破量价、防守趋势、回撤修复、集中持仓和状态择时等候选。
3. 用四周或八周刷新降低交易频率，并加入持仓缓冲和交易成本。
4. 用全样本夏普、年化收益、回撤、换手和最少有效周数共同选择候选。
5. 短样本高夏普被剔除或重罚；当前最少有效周数为 120 周。
6. 输出当前信号日、多股当前位置、目标权重、六类技术分位和全样本净值诊断。

## 当前冻结结果

快照文件：`board/quant_strategy_agent_vnext/data/kline_multiscale_expert_challenger.json`。

- 模型三入选：全历史状态择时趋势低频，股票池为全 A。
- 有效周数：224 周。
- 全历史年化收益：约 8.84%。
- 全历史夏普：约 0.53。
- 最大回撤：约 -26.59%。
- 周均换手：约 0.12。
- 当前信号日：2026-06-30，输出 80 个当前位置候选。

说明：曾出现 1.51 的短样本夏普候选，但只有 3 个有效周，已按护栏排除，不作为冠军。

## 参考框架

- Qlib 的 Alpha158/Alpha360 思路：先看 IC/RankIC，再看组合层收益、回撤和信息比率。
- TA-Lib 的指标分类：趋势、动量、成交量、波动率、形态识别等，适合作为技术因子族划分参考。
- Wyckoff Agent 思路：记忆、反思、进化和预测闭环可用于模型二，但不能替代回测与治理边界。
