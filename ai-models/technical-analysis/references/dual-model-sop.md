# 技术分析三轨模型 SOP

文件名保留为 `dual-model-sop.md` 是为了兼容旧入口；当前内容已经升级为三轨模型。

## 0. 基本原则

1. 所有信号必须按时间顺序生成，信号日只能使用当日收盘及以前可获得的数据。
2. 次日开盘或下一可交易价格执行，回测必须扣除换手成本。
3. 模型一和模型二保留训练、验证、封存测试三段分离。
4. 模型三按用户最新需求使用全部成熟历史样本拟合，但必须标记为全历史回溯研究，不声明样本外验证。
5. 不允许把短样本高夏普、空仓低波动或事后拟合说成稳定可交易策略。

## 1. 模型一：纯技术信号栈

输入字段包括开盘、最高、最低、收盘、成交量、成交额、复权因子、股票状态、行业和规模变量。过滤 ST、退市整理、长期停牌、成交额过低和价格异常样本。

六类信号族：

- 趋势动量：短中长期收益、均线斜率、路径效率。
- 突破确认：高点突破、放量突破、强势收盘。
- 回撤反转：上升趋势内回撤、超跌修复、支撑位附近企稳。
- 量价确认：量能扩张、量价同步、成交额改善。
- 波动质量：低噪声趋势、下行波动惩罚、真实波幅约束。
- 防守择时：破位、放量下跌、趋势失效、极端波动和流动性收缩。

训练流程：生成信号族、横截面标准化、训练期计算 RankIC、收缩成权重、组合成综合分、校准单股买卖阈值、输出训练/验证/封存测试绩效。

## 2. 模型二：LLM 记忆多周期

形态专家包括日线趋势、放量突破、趋势回撤、缩量蓄势和周线结构。记忆条目记录触发情境、判断方向、置信度、成功失败样本、适用市场状态、例外分支和修正次数。

学习流程：历史 K 线快照、股票技术结构分组、同类模式学习、训练期监督排序、验证期选候选、封存测试只诊断。失败样本可以进入下一轮预声明训练，不能回头改已观察测试结果。

## 3. 模型三：全历史低频技术拟合

适用场景：用户明确要求“不划分训练测试，全部历史训练，追求高夏普但交易频率不要太高，并输出当前位置”。

流程：

1. 用全部成熟历史收益估计六类技术信号族权重。
2. 生成综合、突破量价、防守趋势、回撤修复、集中持仓、状态择时等候选。
3. 四周或八周刷新信号，配置持仓缓冲，组合层扣除成本。
4. 全样本选择目标为夏普优先，同时惩罚过高换手、过深回撤和过短样本。
5. 候选至少需要 120 个有效周；不足者即使夏普很高也不采纳。
6. 输出当前信号日、当前位置、目标权重、主导信号族和全历史净值诊断。

## 4. 当前发布结论

模型三当前冠军为“全历史状态择时趋势低频”，全 A 股票池，224 个有效周，全历史夏普约 0.53，周均换手约 0.12。它满足低频和历史覆盖要求，但夏普未达到理想的高夏普水平，因此说明中必须如实标记为全历史研究拟合版。

## 5. 下一轮优化设想

- 扩展技术因子：缺口修复、波动压缩突破、趋势回踩质量、成交额结构和市场状态交互项。
- 降低无效换手：加入最短持有期、成交可得性约束和持仓稳定性惩罚。
- 强化状态分层：牛市、震荡、熊市和高波动环境分别估计信号寿命。
- LLM 记忆增强：用相似股票组学习有效形态，但输出必须经过组合层成本和样本长度护栏。
- 前瞻验证：新增未来样本后再做预声明验证，不能把全历史拟合直接当成实盘保证。
