# 技术分析双模型 SOP

## 0. 基本原则

1. 所有信号必须按时间顺序生成，信号日只能使用当日收盘及以前可获得的数据。
2. 次日开盘或下一可交易价格执行，回测必须扣除换手成本。
3. 训练、验证、封存测试三段分离。训练集调结构，验证集选候选，封存测试只报告。
4. 不允许为了提高封存测试夏普回头修改阈值、权重、样本或文案。
5. 若封存测试失败，页面只能标记为研究诊断，不得显示为可部署策略。

## 1. 模型一：纯技术信号栈

### 1.1 数据准备

- 输入字段：开盘、最高、最低、收盘、成交量、成交额、复权因子、股票状态、行业、市值或可替代规模变量。
- 过滤规则：剔除 ST、退市整理、长期停牌、成交额排名过低和价格异常样本。
- 时点规则：所有行业、市值和状态信息必须使用当时可得版本，不能用未来修订值。

### 1.2 因子族

- 趋势动量：短中长期收益、均线斜率、价格相对区间位置。
- 突破确认：高点突破、放量突破、跳空后延续、强势收盘。
- 回撤反转：上升趋势内回撤、超跌修复、支撑位附近企稳。
- 量价确认：量能扩张、量价同步、成交额改善、换手活跃度。
- 波动质量：低噪声趋势、下行波动惩罚、真实波幅约束。
- 防守择时：破位、放量下跌、趋势失效、极端波动和流动性收缩。

### 1.3 训练流程

1. 生成所有信号族的原始分数。
2. 每日横截面标准化，行业内再标准化。
3. 训练期计算每个信号族对未来收益的 RankIC 和方向稳定性。
4. 根据信号族 IC、ICIR 和覆盖率生成权重。
5. 组合成综合技术评分，并生成残差增量评分和风险预算评分。
6. 单股层面用训练期评分分位数校准买入、持有、减仓、清仓阈值。

### 1.4 回测输出

- 个股择时：历史买卖点、当前信号方向、触发因子、失效条件、净值、回撤、换手。
- 横截面轮动：全市场或指数池内按综合分选股，形成 Top 组合、风险预算组合和多空诊断组合。
- 诊断指标：训练、验证、测试夏普，年化收益，最大回撤，换手，RankIC，胜率。

## 2. 模型二：LLM 记忆多周期

### 2.1 形态专家

- 日线趋势专家：判断趋势方向、强弱和斜率。
- 突破专家：识别放量突破、平台突破和假突破风险。
- 回撤专家：判断趋势中的健康回撤与破位。
- 缩量蓄势专家：识别波动收敛、量能压缩和等待确认状态。
- 周线专家：过滤日线噪声，判断中期结构。

### 2.2 记忆结构

每条记忆包含：触发情境、检索文本、判断方向、置信度、股票样本、成功失败样本、适用市场状态、例外分支和修正次数。新增记忆先做相似检索，再由 LLM 判断 add、skip、replace 或 branch。

### 2.3 学习与进化

1. 用历史 K 线生成专家快照和初始判断。
2. 按股票技术结构、波动状态和趋势阶段做大类划分。
3. 在同类股票内学习形态相似性和信号寿命。
4. 用训练期监督排序学习专家权重。
5. 验证期选择候选策略。
6. 封存测试只做最终诊断，不允许再回头调记忆。

## 3. 发布闸门

候选必须同时满足：

- 训练和验证夏普为正，且不是靠空仓造成的零波动假象。
- 最大回撤低于预设阈值，换手和成本后收益仍可接受。
- RankIC 或胜率方向与组合收益一致。
- 信号生成时间早于执行时间。
- 封存测试结果仅决定是否发布，不参与候选排序。

当前快照下，两条模型链路训练/验证较好，但封存测试夏普为负，因此不能发布为交易策略。

## 4. 下一轮优化设想

- 扩展技术因子：增加缺口修复、波动压缩突破、趋势回踩质量、成交额结构和市场状态交互项。
- 降低换手：把评分变成连续权重，加入持仓缓冲区、最短持有期和风险预算。
- 强化状态分层：牛市、震荡、熊市和高波动环境分别训练信号寿命。
- 单股解释增强：每个买卖点都输出主导信号族、反向证据和失效价格区间。
- LLM 记忆约束：记忆只能改下一轮训练规则，不能改已经打开的测试结果。
- 前瞻验证：新增未来样本后再做一次预声明验证，而不是反复打磨历史测试集。
